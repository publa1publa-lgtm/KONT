# KONT — marketing site

Clean Next.js landing (ported from `contentfabric_site` `/home`). Copy lives in `src/messages/en.json`.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Edit `src/messages/en.json` for all user-facing strings. Add `ru.json` (etc.) and extend `src/i18n/messages.ts` when you need more locales.
